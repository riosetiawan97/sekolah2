## Git & GitHub
- Semua commit memakai identitas pemilik repo:
  `git config user.name "Rio Setiawan"` dan `git config user.email "riosetiawan1997@gmail.com"`.
- Jangan tambahkan baris `Co-Authored-By` atau `Claude-Session` di pesan commit.
- Jika commit terlanjur memakai identitas lain, ubah (amend/rebase) lalu push dengan
  `--force-with-lease`, hanya di branch kerja sendiri (bukan `main`).
- Jangan tulis "Generated with Claude Code", "Generated by Claude Code", atau link sesi Claude
  di deskripsi pull request, komentar, maupun review GitHub.
